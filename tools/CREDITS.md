# Sound credits

All sounds in `sounds/` were generated from scratch in code by `make_sounds.py`
(no recorded samples or third-party audio), so they're free to use anywhere,
including in a game with ads.

To change a sound, edit its function in `make_sounds.py`, run `python make_sounds.py`
(needs numpy and scipy), and copy the new file from `out/` into `public/sounds/`.
